Third-party notices for Jetty

Jetty.app bundles the library and artwork listed below. Each keeps its own
license; the texts and credits they require follow. The weather tile shows
data that Jetty fetches from Open-Meteo at run time; its credit is included.
The Swift runtime and the system frameworks Jetty links ship with macOS and
are not bundled.

Components:
  Haiku Tracker trash icons (LicenseRef-Open-Tracker-License)
  KARSIORI STUDIO Free Pixel Art Trash Pack - Animated (CC0-1.0)
  Open-Meteo weather data (CC-BY-4.0)
  PictKit (Unlicense)
  Tango icon theme trash icons (LicenseRef-Public-Domain)

This file is maintained by hand (Jetty/Resources/Third-Party-Notices.txt in
the repository). ICON-CREDITS.md there records where each Trash style comes
from.
